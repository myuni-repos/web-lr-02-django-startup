# Простой django сайт (Платформа для блогов с настройками читательских предпочтений) (вариант 10)

# Как запустить
## Склонинруйте репозиторий
`git clone <ссылка на репозиторий>`
`cd lr-02-django-startup`

## Подготовка к запуску
### Создание venv
`python3 -m venv venv`
`source venv/bin/activate`

### Установка зависимостей
`pip install -r requirements.txt`

## Запуск
`python manage.py runserver`
Откройте браузер и перейдите по адресу:
http://127.0.0.1:8000/
